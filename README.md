# SocialBudi Cookie Extractor

Chrome extension to easily extract LinkedIn cookies for SocialBudi scraping services.

## 🎯 Purpose

This extension solves a critical UX problem: extracting LinkedIn authentication cookies is too technical for most users. With this extension, users can extract their LinkedIn `li_at` cookie with one click.

## ✨ Features

- 🍪 One-Click Extraction - Extract LinkedIn cookies instantly
- 🔒 Secure Local Storage - Cookies stay on your device until you send them
- 🚀 Dashboard Integration - Automatic integration with SocialBudi dashboard
- 📋 Clipboard Copy - Copy cookie manually if needed
- 🎨 Clean UI - Simple, professional interface

## 📦 Installation

### Download & Install

1. Download: [Get Extension](https://drive.google.com/YOUR_LINK_HERE)
2. Unzip the downloaded file
3. Open Chrome → `chrome://extensions/`
4. Enable "Developer mode" (toggle top right)
5. Click "Load unpacked"
6. Select the `socialbudi-cookie-extractor` folder
7. Done! Look for SocialBudi icon in toolbar

## 🚀 Usage

### Extract Cookie

1. Log into LinkedIn
2. Click SocialBudi extension icon
3. Click "Extract LinkedIn Cookie"
4. Success! Cookie is stored locally

### Send to Dashboard

1. Go to SocialBudi dashboard
2. Navigate to LinkedIn scraper
3. Extension auto-detects page
4. Click "Send Cookie"
5. Ready to scrape!

## 🔒 Privacy & Security

- **Local Storage**: Cookie stays in browser until you send it
- **No Tracking**: Zero analytics or telemetry
- **HTTPS Only**: Secure connections only
- **User Control**: Delete data anytime
- **Open Source**: Review the code

## ❓ Troubleshooting

**"No cookie found"**
- Ensure you're logged into LinkedIn
- Visit linkedin.com/feed first
- Try extracting again

**Extension not in dashboard**
- Refresh dashboard page
- Check extension enabled in chrome://extensions/
- Verify you're on contentscrapingserver.site
